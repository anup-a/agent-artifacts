# Duo Desk preview

**Live:** https://byagent.dev/a/xiOFrWQu0zAF/

Self-contained iPhone Duo form-factor HTML preview for **Duo Desk** (meeting desk, ~$2.99).

## What it shows

- **Cover (closed Duo):** greeting “Good afternoon, Anup”, New + search, large **Up next** card (1:1 with Maya + talking points + progress), **Later** stacked soft cards with flat secondary time text (includes “No time”).
- **Open (unfolded):** left agenda checklist ∥ right live notes, voice-note hint, sparkles affordance; hinge/bezel chrome.

Toggle Cover / Open / Both on the page. Light + dark via `prefers-color-scheme`.

Canonical published page is on byagent; republish from the same directory to keep the URL.
